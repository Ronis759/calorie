# calorie
🥗 Калории — Трекер питания с ИИ и сканером штрихкодов
<img width="575" height="837" alt="Image" src="https://github.com/user-attachments/assets/1276a42d-25b5-46c2-a2ed-d12de91a5980" />

«Калории» — это современное, легкое и приватное веб-приложение (PWA) для удобного трекинга питания, калорий и БЖУ (белков, жиров, углеводов).

Приложение позволяет избавляться от ручного ввода: вы можете просто сфотографировать тарелку, написать состав блюда обычным текстом или отсканировать штрихкод упаковки.

✨ Основные возможности

📸 Распознавание еды по фото и тексту: Загрузите фото блюда или опишите его простыми словами (например, «гречка 200г и две сосиски») — искусственный интеллект определит ингредиенты, их вес и рассчитает калорийность и БЖУ.

📦 Сканер штрихкодов: Встроенный сканер камер мобильного телефона с автопоиском продуктов в глобальной базе данных Open Food Facts. Если продукта нет в базе — приложение сохранит его локально после первого ввода.

📖 Интерактивный дневник: Автоматическое распределение приемов пищи по времени суток (Завтрак, Обед, Ужин, Перекус) с возможностью точного редактирования каждого ингредиента.

📊 Наглядная статистика и календарь: Кольцевой прогресс калорий с цветовой индикацией превышения нормы, а также календарь со средней статистикой за месяц.

⭐ Избранное: Быстрое добавление частых блюд и продуктов в дневник в один клик.

🔒 Приватность и Local-First: Все данные дневника хранятся исключительно на вашем устройстве в localStorage. Никакая личная история не передается на сторонние сервера.

💾 Резервное копирование: Полный экспорт и импорт вашей базы данных в формате .json (через файл, буфер обмена или системное меню «Поделиться»).

🎨 Кастомизация и Темы: Поддержка светлой и темной тем, а также гибкая настройка акцентного цвета интерфейса.

📱 PWA и Офлайн-режим: Возможность установки на рабочий стол iOS/Android/Desktop с полноценной поддержкой работы без интернета (Service Worker).

🛠 Технологии и архитектура

Приложение построено на базе чистого web-стека без тяжелых сторонних JS-фреймворков, что обеспечивает моментальную загрузку и высокий FPS анимаций:

Frontend: HTML5, CSS3 (с поддержкой safe-area-inset для iOS), Vanilla JavaScript (ES6+).

PWA & Cache: Web App Manifest (manifest.json), Service Worker (sw.js).

Сканирование штрихкодов: ZXing JS (zxing.min.js).

База продуктов: Open Food Facts API (world.openfoodfacts.org).

ИИ-сервер (Backend): Интеграция с Cloudflare Worker для обработки изображений и текста через токенизированные API-запросы.

🚀 Запуск и установка

Локальный запуск

Так как приложение использует Service Worker и доступ к камере, его необходимо запускать через локальный веб-сервер (по протоколу http://localhost или https://):

Клонируйте репозиторий:

git clone https://github.com/your-username/calories-tracker.git
cd calories-tracker


Запустите любой локальный сервер, например:

Node.js (npx):

npx serve .


Python 3:

python -m http.server 8000


Откройте адрес http://localhost:8000 в вашем браузере.

Установка на мобильное устройство (PWA)

Разверните проект на любом статическом хостинге с поддержкой HTTPS (GitHub Pages, Vercel, Netlify, Cloudflare Pages).

Перейдите на сайт с вашего смартфона:

iOS (Safari): Нажмите кнопку «Поделиться» ➔ «На экран "Домой"».

Android (Chrome): Нажмите три точки в углу ➔ «Установить приложение».

🔒 Конфиденциальность данных

Данные вашего дневника, сохраненные штрихкоды и настройки не отправляются на серверы разработчиков.

На сервер отправляются только фото еды или текстовые запросы для их распознавания ИИ.

Обратите внимание: хранилища браузера (localStorage) разделяются между обычной вкладкой браузера и установленным PWA-приложением. Для переноса данных между ними используйте функцию «Экспорт / Импорт» в настройках.
